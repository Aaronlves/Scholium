Target authority: [Document and Research Interface](../../Specification/07-document-and-research-interface.md).

The trailing Inspector has About and Links, using native icon selection and the
shared Paper background. About edits metadata in a stable label/value grid with
fixed family/given-name positions, native edit frames, blur commit and Escape
cancellation. Zotero stays separate from metadata. Note Notifications retain
their scoped route. Attachments offer immersive thumbnails and system Quick Look.

Links has native Incoming/Outgoing controls and a local search. Whole group
headings toggle disclosure; passage buttons locate source without changing the
Document mode. Rows have hover feedback, no persistent selected/visited state.
Only the target line briefly highlights: a 1.4-second fade-in/hold/fade-out,
static under Reduce Motion. No source or selection is replaced by that marker.

Research questions and continuing discussion use ordinary Works Notes. There is
no dedicated research-record window, Inspector mode, Search category, store,
Agent tool, or lifecycle. Agent Changes remains independent operation evidence.
