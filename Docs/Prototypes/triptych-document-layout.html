Double Effect and Moral Description

The principle of double effect is most useful when treated as a claim about the structure of agency, not as a device that mechanically classifies outcomes.

Why description comes first

A moral assessment begins with an account of what the agent was doing, which reasons organized the action, and which descriptions belong to the plan itself.

Two readers may agree about every physical consequence while disagreeing about the practical description under which the agent acts.

The pressure from redescription

A defensible distinction needs constraints on admissible descriptions. Those constraints cannot be supplied by vocabulary alone.
