| Area | Current reachable boundary |

| Move and import | Confirmed moves preflight destination and incoming-link revisions and rewrite only identically resolved links. Stable identity/records follow confirmed moves or reconciled external renames; ambiguity requires confirmation. Unclassified imports remain editable and classify into any vault. | Settlement, Comment, Annotation, and Critique | Settle is a researcher-owned, fingerprint-bound, idempotent activity; legacy Human Review and Qualification remain read-only archives, expose no current creation or editing API, and never become Settled. | Multi-target Write and Fidelity | Write freezes one of four researcher-selected scopes, flushes editors, creates one Before Agent Work checkpoint, and issues a short-lived activity key whose digest alone persists. App/CLI import only Contracts and Application, Core remains internal, one live app runtime has one accepted event subscription, and per-window controllers own independent presentation state. |
| Connections, Search, and Attention | One workspace `GraphSnapshot` owns Vector-Link v1 resolution; neutral/transitive paths never become evidence and legacy syntax remains exact with diagnostics. Attention is limited to specified structural, currency, connection, reliance, metadata, and identity conditions; dismissals are Triptych-local and deadlines machine-local. |
| Editor | CodeMirror Source/Live and sanitized Read share one checked semantic projection and the same callout, table, footnote, math, preview, font, and presentation contracts. | Product Skills | Protected typed resources reject traversal/symlink escape; revisions cover bounded resources and assembly records only loaded conditional resources. ## Retired reachable surfaces

- Proposal/Revision review sheets, Research Task/Session, Agent Assessment, and
  the former Agent Review surface.
- Active-note HTML/PDF export and Canvas.
- Zotero data-folder/SQLite access, additional-vault/All Notes presentation,
  and generated `_index.md`, `_agent-index.json`, or `_agent-context.json`.
- Obsolete Proposal, Research Session, workflow-bridge/readiness/lint,
  pre-release Review-store, and Add Dated Reference implementations.

Unsupported pre-release state is not read into the current interface. The
clean cutover never authorizes deleting or rewriting researcher Markdown,
unknown YAML, or unrecognized Triptych files.
