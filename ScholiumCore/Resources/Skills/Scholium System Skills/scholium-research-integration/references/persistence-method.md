# Persistence method

The active Method supplies a bounded candidate change or Critique output together with its target, purpose, evidential basis, and unresolved risks. This adapter performs no new analysis, synthesis, writing, or criticism.

For Analyze, Synthesize, and Write, the typed write set contains exactly the current Markdown Target. For Critique, that write set remains empty and a separate typed output binding identifies the only writable Critique record. Never treat the Work, Materials, or explanatory prose as additional authority.

Before writing:

1. verify the candidate concerns only the exact write Target or prepared Critique output and operation;
2. verify the starting identity and fingerprint against the matching typed binding;
3. preserve unrelated Markdown, YAML, links, citations, and researcher prose;
4. refuse any property change outside the explicit key set;
5. retain source and agent attribution already present in the candidate.

After writing, reread the changed Target or prepared Critique output, verify the requested change and byte-preservation boundary, and return the final fingerprint. If persistence would require strengthening a claim or resolving an intellectual ambiguity, return to the Method rather than improvising here.
