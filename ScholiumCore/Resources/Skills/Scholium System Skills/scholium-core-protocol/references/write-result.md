# Write Result composition

Use the frozen Write Result Contract. For the current default fields:

- **Writing Outcome** receives the Method's compact judgment about what the
  resulting Work now accomplishes, or why no change was warranted. Do not
  reproduce the Work or turn this field into a change log or section inventory.
- **Change Kind** declares whether the Work was drafted, revised, reorganized,
  clarified, or warranted no change. No-warranted-change is exclusive.
- **Remaining Pressure**, when present, contains only a substantive unresolved
  burden that remains after the authorized writing.
- **Evidence Basis**, when present, contains only the academic evidential basis
  needed to judge the result, not a Material list or operation log.

Exact changed documents and write outcomes are Application provenance. A Write
Result does not claim that Check Fidelity passed unless the researcher
separately initiated that Action. Do not narrate tools, saved bytes, rereads, or
operations as evidence of philosophical success.
