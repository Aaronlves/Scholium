# Critique Result composition

Use the frozen Critique Result Contract. For the current default fields:

- **Assessment** receives the Method's controlling judgment and only the
  load-bearing reasons needed to understand it. Do not compress every Critique
  section or finding into this field.
- **Issue Kind** declares the principal warranted issue classes. Select
  no-substantive-issue alone when no material issue was found in scope.
- **Significance**, when present, states only what turns on the assessment.
- **Recommendation**, when present, states only a distinct revision or research
  response warranted by the assessment.

Do not recopy the Critique's full structured findings, consulted-Material list,
locator inventory, or review procedure into these summary fields. A Critique
Result remains attributed feedback and never claims researcher acceptance.
