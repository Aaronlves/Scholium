# Analyze Result composition

Use the frozen Analyze Result Contract. For the current default fields:

- **Source Reconstruction** receives the Method's primary bounded source-facing
  outcome. Do not duplicate the saved Analysis. When an inspected researcher
  Work materially shaped that outcome, include the attributed relation once in
  this field rather than creating a second summary.
- **Coverage** declares how much of the requested source scope was actually
  completed.
- **Reliability** declares material access, extraction, version, locator, or
  verification limits. Select no-material-limitations only when it is not
  combined with a limitation.
- **Agent Evaluation**, when present, contains only a distinct critical
  judgment or residual pressure.
- **Further Research**, when present, contains only distinct questions or
  directions warranted by this analysis.

Record a material source-access limit once in Reliability. Add a short
qualification to Source Reconstruction only when the limit changes what the
reconstruction can support. Put source-grounded reading leads only in the
structured `literature_recommendations` input and omit it when there are none.
Do not mention tools, commands, access routes, hashes, saved-file checks, or
other Application-owned process facts merely to demonstrate diligence.
Analyze submits no `fidelity_outcomes`; those belong only to an explicitly
researcher-initiated Check Fidelity Run.
