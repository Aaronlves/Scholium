# Check Fidelity Result composition

For the default Check Fidelity Profile, leave `academic_results.values` empty.
Submit the exact attributed `fidelity_outcomes`; Scholium derives **Finding**,
**Finding Status**, and **Suggested Correction** from them without collapsing
mixed or unavailable checks. For a researcher-customized Profile, follow the
explicit academic fields in the returned fillable template instead.

Every outcome remains bound to the checked revision, selected check, evidence,
and actual access limit. Do not repeat the verification sequence, tools, or the
same underlying defect as extra academic prose. No-inconsistency-found means
only that no inconsistency was found within the checked scope; it is not truth,
acceptance, or a general quality certification.
