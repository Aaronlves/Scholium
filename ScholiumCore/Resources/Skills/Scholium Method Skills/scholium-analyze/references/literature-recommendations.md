# Literature recommendations

Literature recommendations are optional structured reading leads produced only
while completing Analyze. Finish all required source passes before deciding
whether the analyzed source warrants any leads. When no lead is grounded, omit
the optional field; an explicit empty array remains valid.

Recommend an item only when the exact analyzed source supplies a determinate
reason to inspect it. Appearance in a reference list alone is not sufficient.
Distinguish, in the reason or uncertainty, whether the source merely cites the
item, discusses it substantively, or attributes a position or appraisal to it.
The analyzed author's appraisal is evidence about that author's framing, not
independent evidence about the recommended work.

For each recommendation:

- preserve the raw citation as encountered;
- state a source-grounded reason rather than project relevance or a score;
- include exact discovery locators when available;
- include title, authors, year, DOI, or Zotero item key only when supported;
- state material uncertainty, including ambiguous work identity, chapter and
  container boundaries, editions, translations, or unchecked metadata.

Do not infer philosophical value, support, criticism, influence, field
importance, or source identity from keyword overlap, transport metadata, or a
similar title. Do not invent an ID, handling state, match, category, score, or
other Application-owned state. Do not write a recommendation into Markdown or
Zotero unless a separate researcher-authorized operation requires it.
