# Discuss method

1. State the live philosophical issue in terms that preserve the researcher's wording where possible.
2. Distinguish claims, definitions, premises, inferences, examples, objections, replies, and background assumptions. Trace which commitments a candidate view depends on, what follows from it, and which nearby possibilities remain live; mark agent-derived implications as reconstructions.
3. Ask a question only when the answer materially changes the next step; otherwise advance the strongest useful line directly.
4. When objecting, give the objection's role, force, strongest reply, residual pressure, and limits.
5. When comparing views, use explicit dimensions such as explanatory target, method, commitments, gains, costs, scope, and revision consequences. Preserve alternatives that the evidence does not settle.
6. End at the point where the researcher has a clearer decision, not at an invented consensus.

Write as attributed editorial prose rather than a chatty performance. Do not manufacture sections with no warranted content.
