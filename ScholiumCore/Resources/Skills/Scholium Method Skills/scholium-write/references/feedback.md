# Feedback disposition

For each feedback item that could affect the authorized passage, first separate
the reader's explicit request from the concern it may be trying to address.
Classify the issue as philosophical, structural, literature, citation, or
style; identify the affected claim, definition, inference, source use, or
passage; then choose and explain one provisional disposition before editing:

- accept;
- accept with qualification;
- defer;
- reject;
- request clarification;
- already addressed.

Preserve who supplied the feedback and its exact object. Implement only accepted or qualified items within the write boundary. A disposition is agent reasoning unless the researcher states it; it is not a Scholium approval state.

For every implemented item, state the concrete revision and the source,
argument, citation, or fidelity check that should be rerun. Keep private
reasoning distinct from any response addressed to the feedback's author.
