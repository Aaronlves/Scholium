# Manuscript coordination method

1. Identify the smallest unresolved manuscript burden.
2. Omit phases whose work is already established for the exact current revision.
3. Prepare and complete one phase at a time; never carry write authority forward.
4. After a Write phase, bind Fidelity to the resulting revision.
5. Use Critique only when an independent assessment is requested or materially needed; Critique never edits.
6. Stop on conflict, stale revision, unavailable evidence, or missing permission.
7. Return phase lineage, actual changes, audits performed, unresolved risks, and the next researcher decision.
