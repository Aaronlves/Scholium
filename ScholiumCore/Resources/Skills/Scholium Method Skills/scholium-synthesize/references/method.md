# Synthesize method

## 1. Establish the conceptual home

Read the current Topic before routing new material. Identify its governing question, distinctions, live positions, objections, and unresolved structure. If the requested material has no genuine role here, leave the Topic unchanged and explain why.

## 2. Classify contributions by evidence

For each actually inspected Material, determine whether it:

- adds a missing concept, argument, case, or distinction;
- corrects an attribution or reconstruction;
- qualifies a claim's scope, force, or evidential status;
- reopens an issue through a live objection, alternative, or unresolved reply.

Do not infer these roles from keyword overlap, backlinks, or selection alone.

## 3. Integrate minimally

Place each warranted result under the existing problem-centered structure. Preserve rival possibilities when no basis settles them. Use explicit prose for relations instead of making connectivity carry philosophical meaning. Avoid duplicating a source Analysis inside the Topic.

## 4. Validate

Reread the Topic and check that source-facing statements remain traceable, agent evaluation remains attributed, and the update has not silently converted a candidate into the researcher's settled view.
