# Manuscript Coordination Method

## 1. Diagnose the stage

Classify the immediate need without pretending that every manuscript follows one linear sequence:

- question and contribution definition;
- source acquisition or source analysis;
- conceptual or argumentative development;
- architecture and drafting;
- local substantive revision or meaning-preserving prose control;
- exact-version content audit;
- independent philosophical review;
- received-feedback processing;
- final researcher decision.

Use the smallest phase that advances the actual burden. Earlier phases may be revisited when later work exposes a source, concept, or argument defect.

## 2. Route to complete workflows

| Need | Primary Workflow Skill |
| --- | --- |
| Find and bound a worthwhile question | `scholium-research-exploration` |
| Analyze a source unit | `scholium-source-analysis` |
| Integrate verified material into an exact note | `scholium-research-integration` |
| Clarify a concept or construct an argument | `scholium-philosophical-development` |
| Organize a bounded research corpus | `scholium-research-synthesis` |
| Architect, draft, or substantively revise prose | `scholium-philosophical-writing` |
| Improve existing prose without philosophical change | `scholium-philosophical-writing` plus selected researcher-owned `scholium-prose-control` |
| Check fidelity and evidential use | `scholium-content-audit` |
| Obtain independent whole-work criticism | `scholium-philosophical-review` |
| Process comments actually received | `scholium-feedback-processing` |

Do not reproduce those methods inside this coordinator. Retrieve and apply each selected package for its own phase.

## 3. Use Mixed mode without leakage

For each phase declare purpose, required skills, read set, write set, permission, output, stop condition, durability, and handoff. The maximum write set is the original researcher-authorized scope; each phase receives only a subset. A later phase does not inherit an earlier phase's permission or accept its philosophical conclusions automatically.

Ordinarily audit the final substantive changed fingerprint once. Run an earlier independent audit only when a phase's handoff must itself become durable evidence before later work can responsibly proceed.

## 4. Preserve authorship and evidence

- Keep source claims, researcher claims, agent proposals, review findings, and received feedback distinct.
- Preserve the researcher's intended thesis during authorized revision.
- Mark novelty, significance, completeness, and publication-placement claims as unverified unless the relevant literature and context were checked.
- Keep gate judgment separate from evidence state: a manuscript may be structurally complete while source verification remains open.
- Require a standalone manuscript to carry its own question, concepts, argumentative burden, and terminology rather than silently depending on private project architecture.
- Never promote a reviewer recommendation, audit pass, or fluent draft into researcher acceptance.
