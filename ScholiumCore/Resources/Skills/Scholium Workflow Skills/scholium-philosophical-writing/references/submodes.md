# Philosophical-Writing Permission Submodes

The submode controls what may be returned or written. It does not determine the philosophical method or silently authorize a change in substantive commitments.

## `advisory-only`

Diagnose, outline, explain, or suggest improvements without providing an exact replacement and without modifying files.

Use when the philosophical structure is unstable, the researcher wants guidance, or the target and permission are not exact.

## `patch-proposal`

Provide exact candidate text or a bounded replacement without writing to the file. State what the patch preserves, what it changes, and any substantive alternative excluded from it.

Candidate prose is not settled content merely because it is polished.

## `authorized-file-edit`

Edit only the exact file and section authorized in the current packet.

Before editing:

- inspect the current text and revision;
- identify the intended thesis and local function;
- preserve unrelated content, Markdown, YAML, links, and citations;
- state any substantive change affecting claim strength, concept, source role, inference, or dialectical position.

After editing, reread the changed context and mark the exact fingerprint `audit-needed` when the change is philosophically substantive or source-dependent. Let the Core Protocol schedule one audit for the final version.

## Submode boundary

Moving from advice or candidate text to a file edit requires a fresh permission determination. Do not treat acceptance of an idea as authorization to edit an unspecified target.

Use `scholium-prose-control` as a separately selected researcher-owned specialist when the task is limited to meaning-preserving improvement of existing prose. The same permission submodes apply, but the Prose Control package owns its preservation ledger and style method.
