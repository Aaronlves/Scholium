# Revision Output Contracts

Use only the smallest structure that helps.

## Candidate revision

- Passage function and controlling claim
- Current problem
- Candidate text
- What is preserved
- Philosophical effect
- Source checks
- Remaining pressure

## Argument repair

- Target claim and intended force
- Premises, support, bridge, scope, and burden
- Defect
- Repair and provenance
- Strongest objection
- Reply cost and residual pressure

## Feedback disposition

- Feedback item and provenance
- Faithful concern
- Affected material
- Recommended and researcher disposition
- Reason
- Authorized change
- Checks to rerun

## Completed edit

- Academic change
- Exact Target and final fingerprint
- Authorized range
- What remained unchanged
- Pending Content or Citations checks
- Fidelity state
