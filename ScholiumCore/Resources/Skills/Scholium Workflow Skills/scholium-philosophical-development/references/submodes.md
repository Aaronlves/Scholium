# Philosophical-Development Submodes

## `concept`

Use for a concept, definition, distinction, condition, terminology choice, or conceptual relation.

Required sequence:

1. Identify the formulation and its philosophical role.
2. Distinguish the researcher's formulation, source-derived use, ordinary-language characterization, and agent proposal.
3. Classify the formulation type.
4. Test scope, contrast class, role, cases, counterexamples, dependencies, and conceptual drift.
5. Trace affected arguments and source interpretations.
6. Present alternatives and downstream costs before any authorized change.

Do not revise dependent arguments inside this submode. Return those changes as candidates or restart in `joint`.

## `argument`

Use for a thesis, premise, inference, complete argument, objection, reply, concession, burden, or argumentative relation.

Required sequence:

1. Identify the exact target and conclusion.
2. Separate source reasoning, researcher reasoning, reconstruction, and agent repair.
3. Reconstruct premises, support, link, force, scope, assumptions, and burden.
4. Test the strongest relevant objection.
5. Compare possible replies, concessions, or narrower conclusions.
6. State residual pressure and dependencies.

Do not alter a load-bearing definition inside this submode. Return the conceptual change as a candidate or restart in `joint`.

## `joint`

Use only when the same task changes a load-bearing concept or definition and one or more dependent arguments.

Run in this order:

1. **Concept phase** — state old and proposed formulations, formulation type, scope, role, and consequences.
2. **Argument phase** — reconstruct the affected reasoning under both formulations.
3. **Dependency check** — identify what survives, fails, strengthens, weakens, or becomes circular.
4. **Dialectical check** — identify objections created, removed, or transformed.
5. **Permission check** — determine authorization separately for every conceptual and argumentative target.

Joint analysis does not create joint write permission. If partial edits would falsely represent an unaccepted formulation or leave the research record internally misleading, keep the whole change set as candidates.

## Submode reset

When switching submodes, rebuild the read set, write set, permission, and assumptions. A formulation developed in one submode remains a candidate input until the researcher accepts or authorizes it.
