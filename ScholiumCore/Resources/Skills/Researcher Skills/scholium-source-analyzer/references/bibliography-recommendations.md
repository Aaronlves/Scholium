# Bibliography Recommendations

Use this reference only after the analyzed source unit completes all required passes. Recommended Bibliography is available only for an Analysis in Scholium Research. Its rows are reading leads, not evidence; it does not write Markdown or Zotero.

## Screen conservatively

The optional goals are:

- Background Reading
- Core Positions
- Historical Predecessors
- Objections
- Replies
- Companion Literature
- Alternative Approaches
- Missing Citations
- Recent Developments
- Classic Works

No selected goal means neutral, source-centered screening. Recommend a source only when the analyzed unit supplies a determinate reason to inspect it. A valid analysis may produce zero recommendations.

Do not recommend an item merely because it appears in a reference list. Do not assign Project Relevance or Debate Importance to an unread candidate. Preserve chapter authorship separately from an edited volume and do not silently identify chapters with books, editions with translations, or ambiguous title-only records.

## Evidence distinctions

For every candidate distinguish:

- present only in the reference list;
- cited in the paper's text;
- substantively discussed;
- explicitly praised, criticized, or treated as central by the author;
- independently metadata-verified;
- independently source-inspected.

The author's appraisal is evidence about authorial framing, not independent proof of the recommended source's quality or claims.

```text
Authorial framing: central | praised | criticized | neutral | unclear
Metadata independently verified: yes | no
Source independently inspected: yes | no

```

Preserve exact discovery provenance. Do not infer missing metadata, philosophical value, support, criticism, or field importance from transport metadata or keyword overlap.

For a prepared Scholium request, submit only the structured candidates and exact inspected source scope using the supplied request ID, fingerprint, and confirmation token. Scholium owns duplicate matching and dismissal state. A stale or malformed submission must not replace the prior list.
