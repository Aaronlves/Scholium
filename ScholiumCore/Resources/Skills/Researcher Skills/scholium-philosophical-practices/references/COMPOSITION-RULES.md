# Practice Composition Rules

## 1. Default to supplementation

A selected Practice supplements the official Workflow Skill at its declared editable points. It may sharpen questions, add criteria, alter the order of intellectual attention, or request an additional output. It does not replace the complete workflow merely because it covers related subject matter.

Record each selected Practice by stable ID and exact revision or fingerprint.

## 2. Require an explicit replacement target

Treat a Practice as replacing official guidance only when the researcher or Researcher Skill explicitly names:

```text
Practice:
Practice revision:
Official editable point replaced:
Replacement scope:
Reason:
Unchanged official requirements:
```

Replacement applies only to the named editable point. The Core Protocol, evidence hierarchy, task scope, permission, application operation contract, and non-fabrication requirements are never editable through a Practice.

If the researcher wants to replace the whole executable workflow, use an independent Researcher Skill rather than disguising the replacement as a Practice overlay.

## 3. Allocate distinct jobs

Before composing Practices, assign each one a non-duplicative responsibility. For example:

- Historical Interpreter: textual and historical framing;
- Conceptual Analyst: distinctions, uses, and dependencies;
- Argument Reconstructionist: premises, inference, and charitable repair;
- Dialectical Partner: objections, replies, and costs;
- Thesis Architect: contribution and paper-level burden;
- Philosophical Expositor: communicative realization of an already selected structure.

When two Practices ask the same question, combine the evidence once and preserve any difference in standards or conclusions.

## 4. Resolve conflict transparently

Apply this order:

1. Core Protocol and active product boundary;
2. current researcher instruction, exact scope, and permission;
3. complete official Workflow Skill except at explicitly replaced editable points;
4. researcher-declared Practice precedence, if any;
5. otherwise preserve the methodological disagreement for researcher judgment.

Do not average incompatible criteria, silently choose the more permissive method, or let the last-loaded Practice win by accident.

## 5. Report only material influence

Name a Practice in the completion report only when it materially changed the procedure, evaluation, or result. Include a conflict note when choosing among Practice recommendations would change a philosophical commitment, evidential judgment, or durable edit.
