# Practice Library Catalog

Read this catalog only when explicitly maintaining, extending, or comparing the researcher-owned Practice library. During an ordinary philosophical run, Application supplies exact selected Practice IDs and resources; do not load this directory or any unselected Practice.

- `research-explorer` — [Research Explorer](Research-Explorer.md): questions, stakes, research gaps, and bounded directions;
- `historical-interpreter` — [Historical Interpreter](Historical-Interpreter.md): textual and historical context;
- `conceptual-analyst` — [Conceptual Analyst](Conceptual-Analyst.md): concepts, distinctions, uses, and relations;
- `argument-reconstructionist` — [Argument Reconstructionist](Argument-Reconstructionist.md): reasons and inference with textual repair kept separate;
- `dialectical-partner` — [Dialectical Partner](Dialectical-Partner.md): objections, replies, revisions, and costs;
- `systematizer` — [Systematizer](Systematizer.md): dependencies, structures, and tensions;
- `thesis-architect` — [Thesis Architect](Thesis-Architect.md): thesis, contribution, burdens, and Work architecture;
- `philosophical-expositor` — [Philosophical Expositor](Philosophical-Expositor.md): clear realization of philosophical structure in prose;
- `reviewer` — [Reviewer](Reviewer.md): Critique-only calibration of genre, audience, stage, thresholds, and strengths to preserve.

The protected Core Protocol and this package entry remain the shared philosophical and composition foundation. This catalog supplies discovery only; it does not grant permission, supply evidence, replace a complete primary method, or change a Practice's compatibility.
