# Edmund-derived native editor

ScholiumEditor derives from Edmund v0.8.0, commit
`30ef6cb19317a597489f46eab8ae1bc12d1fccf0`, https://github.com/I7T5/Edmund.
Original source is licensed under Apache-2.0; see LICENSE. Copyright and
third-party notices in source/resources remain in place.

Scholium maintains this source directly. Changes include exact UTF-8 source
projection and range mapping, source-preserving edit transactions and Undo,
native reading guards, session notifications, pointer-selection stability,
and code-background drawing beneath native selection.
