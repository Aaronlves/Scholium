# Scholium Manuscript

Apply scholium-core-protocol. This package is an orchestrator, not an omnibus philosophical authority. Application resolves each phase independently and records the exact package and loaded-resource revisions.

## Establish the function packet

Record the current Work identity and fingerprint, research question, thesis or controlling claim and status, genre, audience or venue when supplied, Research Unit, Materials, current stage, maximum write range within the Work, checkpoint identity, desired result, and stop condition.

The Work remains the only document Target. Materials are read-only in every phase. A Before Agent Work checkpoint is required before any writing phase. No phase inherits permission or accepted conclusions from another.

## Load the coordinator

Read references/method.md completely. When the packet is marked as a
method-selection preflight, inspect the Work and declared evidence read-only
and use `scholium function select-methods` to select `manuscript_gates` only
when the researcher asks about completion, circulation, or submission
readiness. An explicit empty selection keeps the complete coordinator alone.
Execute only the finalized packet and never retrieve an unattached reference
through the generic skills command.

If an explicit researcher-owned Practice is selected, load it only in the phase for which it is relevant and record the resource revision. Do not let it leak into later phases automatically.

## Declared function phases

The coordinator declares the smallest phase plan warranted by the actual work; it does not impose a universal three-phase sequence. It may request only these ordinary Work functions:

- Revise for conceptual, argumentative, feedback-responsive, or expository Work development and the only substantive Work mutation;
- Fidelity for revision-specific Content and optional bound Citations checks;
- Critique for independent read-only assessment with a separate Critique record.

Dialogue may transport instructions and record responses, but it is not a manuscript phase or write permission. Human Review is performed by the researcher and has no skill. Source Analysis remains outside this Strip function set.

## Execute

1. Diagnose the actual manuscript stage and smallest next gate.
2. Ask Application to prepare only the phase currently needed from the declared plan; do not pre-prepare later phases.
3. For every phase rebuild Target and Material fingerprints, read set, write set, permission, method, output, stop condition, and durability.
4. Treat each output as a labeled handoff, not settled manuscript content.
5. After the last substantive edit, run Fidelity once for the exact final fingerprint and selected checks.
6. Run Critique independently when appropriate; do not let Revision pre-seed its findings.
7. Report evidence state separately from readiness judgment.
8. Stop before circulation, email, upload, submission, or publication without a separate explicit external-action request.

## Return

Report current stage, gate addressed, phases and exact versions, academic result, evidence state, Fidelity and Critique state, blockers, researcher decisions, next bounded phase, and at most ready for researcher submission decision.
