# Scholium Manuscript Workflow

Apply `scholium-core-protocol`. This package coordinates existing complete workflows; it does not duplicate their methods, authorize submission, or turn an agent judgment into publication readiness.

## Establish the manuscript packet

```text
Mode: manuscript
Exact Work and fingerprint, if one exists:
Research question:
Candidate thesis or controlling claim and status:
Genre, audience, venue, and deadline when supplied:
Research Unit:
Available Analyses, Topics, sources, and feedback:
Current stage:
Read set:
Maximum write set:
Permission:
Desired outcome:
Stop condition:
Durability:
```

## Load the coordinator

Read [references/method.md](references/method.md) completely. Read [references/publication-gates.md](references/publication-gates.md) when the researcher asks about completion, circulation, submission readiness, or the next gate.

## Apply selected Philosophical Practices

If an explicit Practice is selected, load only that researcher-owned reference plus `COMPOSITION-RULES.md`, and record its stable ID and package revision; otherwise load no Practice. Compatible Practices are `thesis-architect`, `philosophical-expositor`, `systematizer`, and `reviewer`.

## Execute as isolated phases

1. Identify the manuscript's actual stage and the smallest next gate.
2. Select only the ordinary Workflow Skills needed for the current request.
3. Use Mixed mode when two or more operations are required; reset context, assumptions, permission, and write subset between phases.
4. Preserve each phase result as an explicit handoff. Do not treat analysis, development, review, feedback, or an agent-generated formulation as accepted manuscript content merely because a later phase uses it.
5. Bind audit and review judgments to exact fingerprints.
6. Keep citation-format work outside the official package unless the researcher selects an appropriate specialist skill.
7. Stop before any external submission, upload, email, or publication action unless a separate explicit instruction authorizes that external action.

## Return

```text
Current manuscript stage:
Gate addressed:
Phases completed and exact versions:
Academic result:
Evidence state:
Audit and independent-review state:
Remaining blockers and revision burdens:
Researcher decisions needed:
Next bounded phase:
Readiness statement: not assessed | not ready | ready for researcher submission decision
```

The strongest agent verdict is **ready for researcher submission decision**. The researcher remains the author and final authority.
