# Scholium Critique

Apply scholium-core-protocol. The Work is an immutable read-only Target for this function. The only writable scholarly artifact is the separate attributed Critique record supplied by Scholium.

## Establish the function packet

Record the Work identity and fingerprint, Whole or Passage scope, exact selection when applicable, selected Work Comments, read-only Materials, genre, audience, stage, review question, source access, Critique destination, and stop condition.

Reject an unavailable or changing Target. Do not issue a whole-Work judgment from Passage scope. Comments are researcher evidence about concerns; they are not automatically correct findings or permission to edit.

## Load the method

Read references/method.md completely. When the packet is marked as a
method-selection preflight, inspect the Work and Materials read-only and use
`scholium function select-methods` to select `critique_report_template` only
when a structured Whole critique materially helps; an explicit empty selection
keeps the complete primary method alone. Execute only the finalized packet and
never retrieve an unattached template through the generic skills command. Do
not force the full template onto a Passage critique.

If an explicit researcher-owned Reviewer Practice is selected, load only that exact resource and composition rules and record its revisions. Preserve methodological disagreements with the official method.

## Execute

1. Calibrate standards to the Work's genre, philosophical task, audience, and stage.
2. Build the strongest charitable map before criticism.
3. Apply independent conceptual, argumentative, interpretive, dialectical, and expository lenses within the selected scope.
4. Verify source-dependent findings when available; qualify or withhold them when evidence is missing.
5. Bind every material finding to a determinate target and locator.
6. Separate defects, plausible concerns, optional improvements, and missing verification.
7. Prioritize revision burdens without drafting replacements or modifying the Work.
8. Write the attributed result only to the designated Critique record after rechecking the Work fingerprint.

## Return

Lead with scope, exact Work version, strongest contribution, decisive concerns, ordered revision burden, source limitations, and researcher decisions. A Critique is evidence for later judgment; it is not Human Review, Fidelity, accepted feedback, an authorized revision, or publication approval.
