# Source Clusters and Multi-Author Works

Use this reference for edited volumes, multi-author companions or handbooks, chapter sequences, and bounded groups of sources. It does not change the default rule for a single-author monograph: maintain one cumulative source-level Analysis unless the researcher requests independently durable chapter Analyses.

## Define the units

- Treat each independently authored chapter or paper as its own analysis unit.
- Treat an editor's introduction as a debate-framing source unless it also advances an argument requiring close reconstruction.
- Do not merge several authors into one attributed position or one report.
- For a single-author monograph, analyze bounded session units but update the same coherent source-level Analysis by default.

## Pre-pass inventory

Before analysis, establish a bounded inventory:

```text
Cluster purpose and boundary:
Item order:
Author and title:
Parent source, year, and stable identifier when verified:
Available source and access state:
Printed and digital locator systems:
Existing Analysis target, if any:
Expected output and permission:
```

Maintain an ephemeral progress ledger containing item state, three-pass state, output target, audit state, handoff state, and unresolved access or metadata issues. Persist it only when the researcher explicitly asks for a durable ledger.

## Sequential routine

For each item:

1. establish the exact analysis unit and source identity;
2. complete Orientation, Analytical, and Review passes over that unit;
3. produce or update one coherent Analysis appropriate to that source;
4. audit the exact durable version when substantive content changed;
5. create only warranted handoff candidates;
6. record a concise checkpoint and move to the next item only after validation.

If interrupted, resume from the last fully validated item. A draft report, partial pass, or unverified locator does not count as completion.

## Cluster-level synthesis

Do not infer a cluster consensus. After individual analyses are complete, use `scholium-research-synthesis` for a separate comparison of positions, concepts, arguments, tensions, and omissions. Preserve authorial differences and source roles throughout.
