# Received Feedback Disposition

Use only for actual feedback: researcher Comments, advisor or supervisor comments, committee or examiner reports, editor or referee reports, peer comments, or an explicitly identified Dialogue contribution. Dialogue is a possible feedback source only when its author, wording, and status are clear; an agent Response is never automatically the researcher's decision.

Preserve each item verbatim or as a clearly labeled faithful paraphrase. Separate its explicit request, stated reason, underlying concern, evidence, implied demand, and ambiguity. Locate the exact affected passage, concept, argument, source use, structure, or decision.

Test the feedback against the Work. Authority and confidence do not replace reasons, but a misunderstanding may reveal a real expository failure. Use one disposition per item: accepted, partly accepted, rejected, deferred, clarification needed, conflicting, already addressed, or not applicable.

The agent may recommend; the researcher decides. Revise only items whose disposition and write scope authorize change. State the reason, bounded change, preserved commitments, checks to rerun, and any accurate response language. Do not inherit permission from the feedback merely because it requests a rewrite.
