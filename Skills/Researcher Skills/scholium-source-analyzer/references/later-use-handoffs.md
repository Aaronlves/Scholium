# Later-Use Research Handoffs

Use this reference only after source analysis when the researcher requested possible later uses. A handoff is a bounded proposal, never a note update, accepted source relation, or researcher decision.

```text
Possible target or research question:
Proposed source role:
Claim, argument, concept, case, or passage:
Stable locator:
Verification state:
Neutral possible use:
What the source is not evidence for:
Limitation or misuse risk:
Required next check:
Researcher decision needed:
```

Keep authorial self-positioning, analyst reconstruction, independently verified context, and proposed research use distinct. Prefer one well-supported handoff to a long list of thematic overlaps. If the researcher has no mature position, remain neutral rather than designing one implicitly.
