# Source Clusters and Multi-Author Works

Use this reference for edited volumes, multi-author companions or handbooks, chapter sequences, and bounded groups of sources.

## Define independent units

- Treat each independently authored chapter or paper as its own analysis unit.
- Treat an editor's introduction as debate framing unless it advances an argument requiring separate reconstruction.
- Do not merge several authors into one attributed position or report.
- For a single-author monograph, bounded session units may contribute to one cumulative source-level report when the researcher wants that durable form.

Before analysis, record the cluster boundary, item order, author and title, parent source, available version, access state, locator systems, and expected output.

## Sequential routine

For each item:

1. verify identity and define the exact unit;
2. complete Orientation, Analytical, and Review passes;
3. produce the bounded analysis;
4. create only warranted follow-up or handoff candidates;
5. record unresolved access and metadata problems before moving on.

If interrupted, resume from the last fully reviewed item. A partial pass or unverified locator does not count as completion.

## Cluster comparison

Do not infer a cluster consensus. Compare positions, concepts, arguments, tensions, and omissions only after the individual analyses are complete, while preserving authorship and evidential role.
