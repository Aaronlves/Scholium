# Source-Analysis Forms

Choose the narrowest form that satisfies the request. Every form remains read-only with respect to Scholium notes.

## `analysis-only`

Analyze the source without project-use proposals. Use when the researcher wants understanding, supplies no project context, or provides only enough access for a provisional analysis.

## `analysis-with-handoff-candidates`

Analyze the source and propose a small number of bounded possible uses. Label each candidate's role, source basis, locator, verification status, limitation, and required next check. A candidate is not a file update, accepted relation, or researcher commitment.

## `topic-map`

Use for a genuine survey, overview, introduction, textbook, or reference source whose philosophical function is to organize a domain. Map questions, positions, distinctions, motivations, costs, and omissions. Preserve the source's organizing narrative as its narrative rather than independently verified field history.

## `hybrid`

Use when one source genuinely combines an overview function with an original philosophical intervention. Separate the topic map from close reconstruction. The source's overview authority does not automatically support its argument, and its argument does not independently verify its field history.

## Later use in Scholium

If analysis reveals a warranted note-development task, finish the source analysis first. Any persistence or note change begins separately with an exact target, current fingerprint, explicit permission, and the relevant Scholium operation. Do not carry source read access into note-write authority.
