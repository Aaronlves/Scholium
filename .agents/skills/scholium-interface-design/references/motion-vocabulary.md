# Motion vocabulary

Name the closest conventional term and define it in one sentence. Contrast at
most two alternatives when ambiguity matters; vocabulary does not authorize an
effect in Scholium.

Use current platform sources for exact framework terminology. Common families:

- **Appearance:** fade, reveal, insertion, removal.
- **Geometry:** translation, scale, rotation, transform origin.
- **Continuity:** crossfade, morph, shared element, layout transition,
  direction-aware navigation.
- **Disclosure:** expand, collapse, accordion.
- **Manipulation and feedback:** hover, press, drag, reorder, rubber-banding,
  symbol replacement.
- **Timing:** keyframes, stagger, delay, easing, spring response, overshoot,
  momentum, interruptibility.
- **Diagnosis and adaptation:** dropped frames, jank, repeated motion, reduced
  motion, and complete non-motion state.

When reporting, connect the term to the observed object, from/to states,
purpose, owner, and evidence instead of supplying a generic animation recipe.
